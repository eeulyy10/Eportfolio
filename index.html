Building the AI project source code was the most technically intensive artifact in this portfolio. It required applying deep knowledge of convolutional neural networks, image preprocessing pipelines, transfer learning, and model evaluation all grounded in mathematical and engineering principles (SO A). We designed and ran multiple experiments comparing a custom CNN against a MobileNetV2 transfer learning model, then analyzed accuracy curves, confusion matrices, and classification reports to interpret the results (SO B). Designing the full pipeline from dataset splitting to Gradio deployment and TFLite conversion required making real engineering decisions under constraints like limited training data and local hardware (SO C, E). The project was developed collaboratively as GROUP 2, with members dividing responsibilities across model architecture, data handling, evaluation, and deployment (SO D, L). The use of TensorFlow, Keras, scikit-learn, Gradio, and TFLite reflects the ability to leverage modern, industry-relevant tools (SO K). The application itself — detecting whether broccoli is fresh or spoiled addresses a real-world food quality problem, demonstrating that AI engineering can have practical societal value (SO H, J).

Reflection

This project is the one I am most proud of from this semester. Going from raw image data to a deployed Gradio interface and a TFLite model that can run on a mobile device felt like a real engineering accomplishment. It showed me that I am capable of building a complete AI system end-to-end, not just running tutorial code. The fine-tuning phase using MobileNetV2 where validation accuracy hit 98.44% also made transfer learning feel concrete and real rather than just a concept in a lecture slide. Working as a group taught me how to coordinate technical decisions, resolve disagreements about approach, and deliver a working product together. This experience reinforced my goal of building practical, deployable AI systems as a future computer engineer.
